# Данные

В эту папку добавляется CSV-файл с обезличенными данными по мероприятиям.

Рекомендуемое имя файла:

```text
hackathon_events_real.csv
```

CSV-файл должен содержать следующие колонки:

```text
event_name;event_type;event_format;start_date;end_date;registrations_count;participants_count;teams_count;submitted_projects_count;finished_participants_count
```

Важно: не добавляйте в публичный репозиторий персональные данные участников, email, телефоны, закрытые названия клиентов и внутреннюю коммерческую информацию.

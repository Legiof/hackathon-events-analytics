# Анализ хакатонов и IT-мероприятий

## Описание проекта

Проект посвящён анализу хакатонов и IT-мероприятий. Цель проекта - изучить воронку участия, динамику мероприятий, распределение событий по размеру и ключевые метрики завершения.

Проект выполнен как учебный аналитический кейс для развития навыков SQL, PostgreSQL и Apache Superset. Тематика выбрана на основе практического опыта в организации IT-мероприятий, хакатонов и соревнований.

## Стек

- PostgreSQL
- SQL
- Apache Superset
- CSV
- GitHub

## Бизнес-вопросы

В рамках проекта рассматриваются следующие вопросы:

1. Сколько пользователей регистрируются, участвуют и доходят до завершения мероприятия?
2. На каком этапе воронки происходит основная потеря участников?
3. Какие типы мероприятий показывают лучшую конверсию?
4. Как меняется количество мероприятий и участников по месяцам?
5. Какие события имеют самый высокий процент завершения?

## Данные

В проекте используется датасет по IT-мероприятиям. Одна строка в таблице соответствует одному мероприятию.

Основные поля:

| Поле | Описание |
|---|---|
| `event_id` | ID мероприятия |
| `event_name` | Название мероприятия |
| `event_type` | Тип мероприятия: хакатон, кейс-чемпионат, IT-соревнование |
| `event_format` | Формат проведения: онлайн, офлайн, гибрид |
| `city` | Город проведения |
| `start_date` | Дата начала мероприятия |
| `registrations_count` | Количество регистраций |
| `participants_count` | Количество фактических участников |
| `submitted_projects_count` | Количество сданных проектов |
| `finished_participants_count` | Количество участников, дошедших до завершения |
| `teams_count` | Количество команд |

## Модель данных

Основная таблица проекта:

```sql
it_events
```

Таблица содержит агрегированные данные по мероприятиям и используется для расчёта метрик воронки, динамики и эффективности.

## Основные SQL-запросы

В папке `sql/` находятся запросы для:

- создания таблицы;
- загрузки тестовых данных;
- анализа воронки участия;
- анализа динамики мероприятий по месяцам;
- сравнения метрик по типам мероприятий;
- сегментации мероприятий по размеру;
- поиска событий с лучшей конверсией в участие;
- поиска событий с лучшим процентом завершения.

## Дашборд

Дашборд в Apache Superset может включать следующие графики:

| Чарт | Что показывает |
|---|---|
| Воронка участников | Переход от регистрации к участию, сдаче проекта и завершению |
| Динамика мероприятий по месяцам | Рост или спад активности во времени |
| Распределение мероприятий по размеру | Долю малых, средних и крупных событий |
| Метрики по типам мероприятий | Сравнение хакатонов, кейс-чемпионатов и IT-соревнований |
| Топ событий по завершению | Мероприятия, где больше участников дошли до результата |

## Основные выводы

Предварительные выводы, которые можно проверить после загрузки реальных данных:

1. Основная потеря участников часто происходит между регистрацией и фактическим участием.
2. Крупные мероприятия могут давать больше регистраций, но не всегда показывают лучшую конверсию.
3. Формат мероприятия может влиять на долю участников, дошедших до финального результата.
4. Для оценки качества мероприятия важно смотреть не только на регистрации, но и на завершение.

## Как запустить проект

1. Создать базу данных в PostgreSQL.
2. Выполнить скрипт `sql/01_create_tables.sql`.
3. Для тестового запуска выполнить `sql/02_insert_sample_data.sql`.
4. Выполнить аналитические SQL-запросы из папки `sql/`.
5. Подключить таблицу `it_events` к Apache Superset.
6. Построить дашборд и сохранить скриншоты в папку `dashboard/screenshots/`.

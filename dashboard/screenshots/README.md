# Скриншоты дашборда

В этой папке хранятся скриншоты дашборда Apache Superset.

| Файл | Описание |
|---|---|
| `dashboard_overview.png` | Верхняя часть дашборда: KPI-карточки, динамика регистраций и участников, сравнение участников по форматам и типам мероприятий |
| `dashboard_details.png` | Нижняя часть дашборда: доходимость до завершения по типам и форматам мероприятий, таблица детализации событий |

Скриншоты нужны, чтобы репозиторий был понятен рекрутеру или руководителю без локального запуска проекта.
